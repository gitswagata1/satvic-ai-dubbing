# Roadmap

## Vision

Make high-quality regional-language dubbing affordable for every creator.

## Milestones

### Now

- [ ] Objective evaluation: word error rate, speaker similarity and naturalness ratings
- [ ] Lip-sync-aware timing
- [ ] A Colab notebook for users without a local GPU

### Next

- [ ] More languages (Tamil, Kannada, Bengali, Marathi)
- [ ] Automatic subtitle export
- [ ] Consent and watermarking guidance for voice cloning

### Later

- [ ] Hosted creator tool
- [ ] Studio batch processing
- [ ] Quality benchmark for Indic dubbing

## Where this can go

| Direction | Idea |
| --------- | ---- |
| **Startup** | Regional-language dubbing for creators and educators, priced per minute. |
| **Publication** | Evaluate open-source voice-cloning TTS for Indian languages with human listening tests. |

> Voice cloning needs explicit consent from the speaker. Document and enforce this in any hosted product.
