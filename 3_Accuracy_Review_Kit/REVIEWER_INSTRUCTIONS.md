# Native Reviewer Instructions (Telugu / Malayalam)

You have two things: a **review sheet** (CSV — open in Google Sheets or Excel) and,
once ready, the **dubbed video**. Total time: ~40 minutes.

## Pass 1 — Script check (before/without the video, ~20 min)
Read each row's translation against the Hindi and the English back-translation.
- Priority: rows flagged **health-claim** (dosages, durations, do/don't instructions,
  health promises). A wrong word here is a blocker.
- Also check rows flagged **term-choice** and **unclear-source**.
- For any problem, fill: *issue type* (mistranslation / wrong term / number-unit error /
  register-honorifics / unnatural phrasing), *severity*:
  - **blocker** = meaning is wrong or advice is unsafe
  - **issue** = correct but sounds off / machine-like
  - **preference** = fine, but you'd say it differently
- Write your suggested fix in the target language. Mark row status: OK / FIX.

## Pass 2 — Watch-down (with the dubbed video, ~20 min)
Play the video with the dubbed audio. Flag any row where:
- a word is **mispronounced** so it's misheard or means something else
- the voice glitches, or speech noticeably drifts from what's on screen
- an English loanword sounds wrong to your ear as a native listener

## Register guide (what "correct" sounds like)
Everyday spoken language, like a Telugu/Malayalam YouTuber talking at home —
NOT textbook/news language. English words (juice, motion, research, position...) are
intentional and correct where a native speaker would naturally say them. Respectful
మీరు / നിങ്ങൾ address throughout. If a line sounds like a news bulletin, flag it
as *unnatural phrasing* even if technically accurate.
